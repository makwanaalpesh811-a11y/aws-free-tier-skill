# AWS Free Tier on Termux

Use when a free AWS service is needed: TTS, cloud storage, serverless scheduling, image analysis, OCR. Skip entirely if image generation is the goal — Bedrock API is blocked and Colab is faster.

## Setup

Credentials live at `~/.aws/credentials` (chmod 600) with `[default]` profile. Install:

```bash
pip install boto3
```

Verify:

```bash
python3 -c "import boto3; print(boto3.client('sts', region_name='us-east-1').get_caller_identity())"
```

## Working Services

### Polly (TTS) — best free narration tool
Free: 5M chars/month forever. Neural voices: $6.50/1M chars, standard: $4/1M.

Voice discovery via describe_voices:
```python
import boto3
polly = boto3.client('polly', region_name='us-east-1')
polly.describe_voices(LanguageCode='en-IN')  # Aditi, Kajal, Raveena
polly.describe_voices()  # 41 languages total
```

Synthesize:
```python
r = polly.synthesize_speech(Text='...', VoiceId='Kajal', Engine='neural', OutputFormat='mp3')
open('out.mp3', 'wb').write(r['AudioStream'].read())
```

### S3 — storage & backup
5 GB free forever, 2000 GET + 200 PUT requests/month. Use for Almari backups, video hosting.

### Lambda — serverless tasks
1M requests + 400 GB-sec/month. Auto-thumbnails, S3-triggered processing, cron-like schedules.

### Comprehend — text analysis
1M tokens free for 3 months. Sentiment, entity extraction, language detection.

### Rekognition — image analysis
1000 images free for 3 months. Auto-tagging, face detection, OCR-lite.

### Textract — PDF OCR
1000 pages free for 3 months. Useful for Hindi book scans.

### Transcribe — speech-to-text
30 hours free for 3 months. Hindi audio transcription.

## Pitfalls

**Polly has NO true Hindi (`hi-IN`) voices in any region.** Tested us-east-1, us-west-2, eu-west-1, ap-south-1, ap-northeast-1 — all return 0 voices for `LanguageCode='hi-IN'`. For Hindi narration use `en-IN` (Indian English) voices with Hinglish text (Roman transliteration works, `Kajal` neural is highest quality). Native Hindi voices only available via Edge-TTS (Swara/Madhur).

**Polly `describe_voices` requires full language code.** `LanguageCode='hi'` fails; must be `LanguageCode='hi-IN'` (though hi-IN returns empty). Enumerate with no arg to see all 41 supported languages.

**Not all Polly voices support neural engine.** `Aditi` only supports `standard`. `Kajal` supports both `standard` and `neural`. Check `v['SupportedEngines']` from describe_voices output before calling synthesize_speech.

**AWS Bedrock API is NOT working on Termux.** All `invoke_model` and `converse` calls return `ValidationException: Operation not allowed` for every text and image model (Claude, Nova, Llama, Mistral, GPT, Nova Canvas, Titan). Console Playground works for Nova 2.5 Sonic only. Root cause: Mantle endpoint (bedrock-mantle.us-east-1.amazonaws.com) returns DNS NXDOMAIN across all 10 regions tested — not publicly launched. Bearer tokens generated by Bedrock Console cannot be used from boto3 without MantleConfig support (not in botocore 1.43.x available on Termux).

**Marketplace subscription does not auto-trigger.** Even after invoking a model in Console Playground and waiting 90+ seconds, subsequent boto3 API calls still return `Operation not allowed`. The docs promise auto-subscription on first invoke; this doesn't hold in practice for IAM users created from AWS Console. Root user with AdministratorAccess is not sufficient.

**Boto3 v1.43 is latest on Termux.** No MantleConfig support (`from botocore.config import MantleConfig` fails). Upgrade requires pip source build which fails on aarch64-android.

**Deprecated models still in list_foundation_models.** Titan Image v1/v2, SDXL v0/v1, Claude 3.5/3.7 Sonnet all return `ResourceNotFoundException: model version has reached end of life`. Skip these; check model date suffix in modelId.

## When to Use What

| Task | Use |
|---|---|
| Hinglish narration | Polly `Kajal` neural + SSML |
| Native Hindi narration | Edge-TTS Swara/Madhur |
| English narration | Polly `Joanna`/`Matthew` |
| Cloud backup | S3 (5GB free) |
| Scheduled task | Lambda |
| Video analysis | Rekognition |
| PDF OCR | Textract |
| Sentiment analysis | Comprehend |
| Speech-to-text | Transcribe |
| Image generation | NOT AWS — use Colab SDXL |
| LLM text (Claude/GPT) | NOT AWS — use OpenRouter (already has key) |
